We study how vision-language models trained on Internet-scale data can be incorporated directly into end-to-end robotic control to boost generalization and enable emergent semantic reasoning. Our goal is to enable a single end-to-end trained model to both learn to map robot observations to actions and enjoy the benefits of large-scale pretraining on language and vision-language data from the web. To this end, we propose to co-fine-tune state-of-the-art vision-language models on both robotic trajectory data and Internet-scale vision-language tasks, such as visual question answering. In contrast to other approaches, we propose a simple, general recipe to achieve this goal: in order to fit both natural language responses and robotic actions into the same format, we express the actions as text tokens and incorporate them directly into the training set of the model in the same way as natural language tokens. We refer to such category of models as vision-language-action models (VLA) and instantiate an example of such a model, which we call RT-2. Our extensive evaluation (6k evaluation trials) shows that our approach leads to performant robotic policies and enables RT-2 to obtain a range of emergent capabilities from Internet-scale training. This includes significantly improved generalization to novel objects, the ability to interpret commands not present in the robot training data (such as placing an object onto a particular number or icon), and the ability to perform rudimentary reasoning in response to user commands (such as picking up the smallest or largest object, or the one closest to another object). We further show that incorporating chain of thought reasoning allows RT-2 to perform multi-stage semantic reasoning, for example figuring out which object to pick up for use as an improvised hammer (a rock), or which type of drink is best suited for someone who is tired (an energy drink).

The methodology of the paper is to train Vision-Language-Action (VLA) models by fine-tuning pre-trained Vision-Language Models (VLMs) on robotic trajectory data, where actions are represented as text tokens. Here is a breakdown:\n\n Action Representation: Robot actions are discretized into bins and represented as text tokens, which are then incorporated into the model’s training set along with natural language tokens.\n Model Instantiation: The paper uses two pre-trained VLMs: PaLI-X and PaLM-E. The VLA versions are referred to as RT-2-PaLI-X and RT-2-PaLM-E, respectively.\n Fine-tuning:\n * The pre-trained VLMs are co-fine-tuned on both robotic trajectory data and Internet-scale vision-language tasks (like visual question answering).\n * During co-fine-tuning, the sampling weight of the robot dataset is increased to balance the ratios of robot and web data.\n * The action vector is converted into a string of space separated tokens for fine-tuning. For example: “1 128 91 241 5 101 127”.\n * For PaLI-X, the action bins are directly mapped to the token representing the corresponding integer. For PaLM-E, the 256 least frequently used tokens are overwritten to represent the action vocabulary.\n Output Constraint: The output vocabulary of the model is constrained such that when prompted with a robotic-action task, it will only sample valid action tokens.\n Real-time Inference: To handle the large size of VLMs, the model is deployed in a multi-TPU cloud service, which is queried over a network. This allows for a suitable frequency of control and serving multiple robots using the same service.\n Chain-of-thought prompting: Data is augmented to include an additional plan step before actions, to facilitate multi-stage semantic reasoning.\n\nIn summary, the core idea is to leverage the knowledge encoded in pre-trained VLMs for robotic control by treating actions as another language, allowing the model to learn to map robot observations to actions and enjoy the benefits of large-scale pre-training on language and vision-language data from the web.\n

The core method of this paper is to train vision-language models (VLMs) to output low-level robot actions by representing the actions as text tokens and incorporating them into the training set along with natural language tokens and images. This creates vision-language-action models (VLAs). Here’s a breakdown:\n\n Action Tokenization:\n * Robot actions are discretized into a series of bins. For example, the 6-DoF positional and rotational displacement of the robot end-effector, as well as the level of extension of the robot gripper are discretized into 256 bins uniformly.\n * Each bin is represented by an integer, and these integers are associated with specific tokens in the VLM’s vocabulary.\n * An action vector is converted into a string by concatenating tokens of each dimension separated by spaces, e.g., "terminate Δpos𝑥 Δpos𝑦 Δpos𝑧 Δrot𝑥 Δrot𝑦 Δrot𝑧 gripper_extension".\n\n Co-Fine-Tuning:\n * The VLM is fine-tuned using a dataset combining robot trajectory data (represented as input images and textual task descriptions, and output as tokenized actions) and Internet-scale vision-language data (VQA, etc.).\n * The sampling weight on robot data is increased to balance the training.\n\n Output Constraint:\n * When prompted with a robot-action task, the VLM is constrained to output only valid action tokens.\n * For standard VQA, the model can output the full vocabulary.\n\n Real-time Inference:\n * Large VLA models are deployed in a multi-TPU cloud service and queried over the network for real-time robot control.\n\nIn essence, the core method is a simple, general recipe for turning VLMs into robot controllers by treating actions as another language within the VLM, enabling the transfer of knowledge from internet-scale data to robotic control. The method leverages the backbone and pretraining of vision-language models in learning robotic policies, transferring their generalization, semantic understanding, and reasoning abilities to robotic control.
